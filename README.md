# shikosai34-game-manager

第34回茨香祭 Marico Cafe のボードゲーム利用状況管理システム（ホールスタッフ用フロントエンド）

## 概要
文化祭のボードゲームカフェ運営において、ホールスタッフがスマートフォンから各テーブル・ゲームの利用状況とプレイ時間を直感的に管理できるWebアプリケーションです。

## 主な機能
- **3×4 固定グリッドレイアウト**: 物理配置に合わせたゲームを固定順で表示。1画面で全体の空き/稼働状況を把握可能。
- **ワンタップ開始 & 自動終了目安時刻表示**: 開始ボタンを押すとAPIに `in_use` を送信し、サーバー側で設定された終了予定時刻からカウントダウンを表示。
- **声掛けタイミング通知（超過アラート）**: 残り時間が0以下になるとカードが赤枠で点滅（「声掛け!」表示）。
- **誤操作防止の条件付き確認ダイアログ**: 時間が残っている時の終了時のみ確認ダイアログを表示（超過時は確認なしで即片付け完了へ）。
- **スタッフ認証管理**: 配布された英数字10文字の認証IDを `localStorage` に保持。401発生時やヘッダーの「🔑」アイコンから変更可能。URLにハッシュ（例: `https://.../#aB3xK9mP2q` や `#token=aB3xK9mP2q`）が付いている場合は自動的に認証トークンとして保存・適用されます。
- **定期同期 & 画面復帰同期**: 他スタッフやQR側での更新を反映するため、60秒ごとの自動更新、画面復帰時の自動取得、手動「🔄」更新ボタンを搭載。
- **「結果未確認」エラーハンドリング**: 10秒タイムアウトや500エラー発生時は、自動再送せず現状の一覧を再取得して結果未確認アラートを表示。

## API仕様連携
- **一覧取得**: `GET /v1/ctrl/games`（Authorization: Bearer <認証ID>）
- **状態更新**: `POST /v1/ctrl/status/batch`（`[{"gameId": 1, "status": "in_use" | "available"}]` の厳密2項目配列）
- **ステージング環境**: `https://shikosai-api-staging.sg-tera.workers.dev`

npm run build
