# shikosai34-game-manager

第34回茨香祭 Marico Cafe のボードゲーム利用状況管理システム（ホールスタッフ用フロントエンド）

## 概要
文化祭のボードゲームカフェ運営において、ホールスタッフがスマートフォンから各テーブル・ゲームの利用状況とプレイ時間を直感的に管理できるWebアプリケーションです。

## 主な機能
- **3×4 固定グリッドレイアウト**: 物理配置に合わせた12個のゲームを固定順で表示。1画面で全体の空き/稼働状況を把握可能。
- **ワンタップ開始 & 自動終了目安時刻計算**: ゲームごとの想定プレイ時間から終了予定時刻とカウントダウンを自動算出。
- **声掛けタイミング通知（超過アラート）**: 残り時間が0以下になるとカードが赤く強調表示（「声掛け!」表示）。
- **誤操作防止の確認ダイアログ**: 時間が残っている時の終了時のみ確認ダイアログを表示（超過時は確認なしで即片付け完了へ）。
- **ステータスサマリー & デジタル時計**: 利用中数、空き数、現在時刻をヘッダーに常時表示。
- **API通信ログビューア**: 画面下部のアコーディオンで、APIサーバーに送信・受信されるJSONデータを即時確認可能。
- **状態の自動復元**: ページ読み込み時に利用状況と終了予定時刻を取得・復元（現在はlocalStorage連携、将来REST APIに切り替え）。

## 技術スタック
- React 18
- TypeScript
- Vite
- GitHub Pages (GitHub Actions による自動デプロイ)

## 開発・ビルド手順

### 依存関係のインストール
```bash
npm install
```

### 開発サーバーの起動
```bash
npm run dev
```

### プロダクションビルド
```bash
npm run build
```

### プレビュー
```bash
npm run preview
```

## APIサーバー連携について
`src/services/api.ts` 内にエンドポイント呼び出しロジックを分離しています。
実際のREST APIサーバーと連携する際は、各メソッド内の `// TODO:` コメントを解除し、対応するエンドポイントを指定してください。
